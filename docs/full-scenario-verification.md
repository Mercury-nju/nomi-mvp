## 本轮修复

1. 私信空窗口原先只能识别测试用空标记。现在识别真实已加载、只有明确原生系统提示的空窗口；空白、未知提示、加载中和加载失败均不建立基线。已有消息但仍加载时也不触发承接。
2. 评论输入框明确指向另一人时，原先可能被附近文字中的目标昵称覆盖。现在明确目标必须精确一致；“客户甲”和“客户甲同学”不同，BODY/HTML 不能充当局部目标证据。

修复后已重启实际服务并通过本地 API 再次同步已知客户会话：baselineEstablished=true、syncHealthy=true、messages=0、mode=suggest；监听保持关闭，未开启自动发送。

## 多账号说明

多个账号同时登录应使用彼此独立的浏览器资料目录；同一目录或多个标签页共享登录态，不能作为账号隔离。当前 Nomi 只配置一个抖音账号，不支持在同一工作台运营多个账号。

正式多账号版本需要 account_id 贯穿账号、客户、会话、消息和发送命令；每账号独立浏览器 context、资料目录、执行队列、授权与恢复状态。同一账号内协调操作，账号之间可以并行。本轮没有将单账号隔离测试描述为多账号真实运营验收。
