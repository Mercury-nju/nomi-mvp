本次在既有 Web 原型上增量实现。保留五项导航、纯白与炭黑视觉、任务确认流程、账号隔离、暂停额度保留和账号每日计划上限。未新增 CRM、客户分配、销售跟进、批量导出或真实平台发送。

## 验证结果

- `npm test`：31 项通过，包括原有额度与任务测试、新增去重、消息事实、执行归因、旧状态恢复、策略历史不变测试。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- `node scripts/verify-v11.mjs`：真实 Chrome 无头模式验证指标集合、筛选、搜索、面板、消息、留资、执行往返、策略确认、知识库更新、旧数据兼容、五项导航、持久化及 390px 页面无横向溢出。
- 测试使用隔离浏览器上下文，不清除用户当前浏览器保存的数据。
- 新基准数据约 2,079,257 个字符；浏览器写入本地存储成功，刷新后状态保留。

## 数据边界与未完成项

本轮 18 项原型验收项全部通过，无未完成的原型功能。

真实抖音采集、真实私信发送回执、真实回复同步不在本次原型接入范围，未实现。全部演示客户、来源、消息、回复和联系方式均为虚构。

旧版浏览器保存的记录缺少昵称、原始消息或执行批次关联时，保留已有记录并明确提示暂无数据或数据尚未完整；不重置用户任务、知识库或额度，也不推测补齐历史。完整演示明细用于新建的基准演示数据。开发重置参数 `?reset=demo` 会清空当前本地演示状态，仅在确实需要重新演示时使用。
